# Security

Only the latest version on `main` is supported.

Report security vulnerabilities through this repository's **Security → Report a vulnerability** page:

https://github.com/impolska742/test-on-prod/security/advisories/new

Do not disclose an unpatched vulnerability, credentials, or private repository content in a public issue. Include a minimal reproduction, affected version, and impact. If private reporting is unavailable, do not post sensitive details publicly; ask the maintainer to enable it.

This extension should not send network requests, collect analytics, load remote code, or require GitHub credentials. Treat requests to add those capabilities as security-sensitive changes.
